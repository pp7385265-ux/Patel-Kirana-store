# Patel Kirana Store - Enhanced Version

A modern, colorful web application for managing a kirana store with user authentication, admin panel, and payment integration.

## Features

### 🔐 Authentication System
- **Simple Login/Registration**: Users login with mobile number, name, and password
- **Auto-registration**: New users are automatically registered on first login
- **Forget Password**: Direct password reset functionality
- **Password Visibility Toggle**: Show/hide password option
- **Admin Login Button**: Dedicated admin login access

### 👨‍💼 Admin Panel
- **Product Management**: Add, edit, delete products
- **Image Upload**: Upload product images from gallery
- **Order Management**: View and manage customer orders
- **Offer Management**: Create discount offers for categories
- **Dashboard Stats**: Real-time statistics and analytics

### 🛒 User Features
- **Product Browsing**: Browse products by category
- **Shopping Cart**: Add/remove items, quantity management
- **Offer System**: Automatic discount application
- **Profile Management**: Update personal information and profile picture
- **Location Tracking**: GPS-based location for delivery
- **Bill Generation**: PDF bill generation and download

### 💳 Payment Integration
- **Multiple Payment Options**: Cash on Delivery and UPI payments
- **UPI Apps Support**: Google Pay, PhonePe, Paytm, Amazon Pay, and others
- **Dynamic QR Code**: Admin's payment QR code with order amount
- **UPI ID**: 8115910227@paytm

## How to Use

1. **Start Shopping**: Click "Start Shopping" on the landing page
2. **Login/Register**: Enter mobile number, name, and password
3. **Admin Login**: Click "Admin Login" button for quick admin access
4. **Browse Products**: Explore products by category
5. **Add to Cart**: Select items and quantities
6. **Checkout**: Choose payment method
7. **UPI Payment**: Scan QR code or use UPI apps
8. **Place Order**: Generate bill and confirm order

## Admin Features

1. **Login as Admin**: Use admin credentials
2. **Manage Products**: Add products with images from gallery
3. **Create Offers**: Set up discounts for categories
4. **View Orders**: Monitor and update order status
5. **Export Data**: Download order reports as CSV

## Payment Flow

- **Cash on Delivery**: Traditional payment on delivery
- **UPI Payment**: 
  - Select UPI payment option
  - Choose preferred UPI app
  - Scan admin's QR code (8115910227@paytm)
  - Pay the exact order amount
  - Order is confirmed automatically
